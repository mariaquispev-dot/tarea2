Guía de contribución – Tienda TECSUP

¡Gracias por tu interés en colaborar con Tienda TECSUP!

Este documento contiene las indicaciones para reportar errores, proponer mejoras y enviar cambios al proyecto.

1. Reportar errores
Si encuentras un error en el funcionamiento de la tienda, sigue estos pasos:

- Ingresa al apartado Issues del repositorio.
- Selecciona New Issue.
- Escribe un título claro que describa el problema.
- Explica qué esperabas que ocurriera y qué ocurrió realmente.
- Indica el archivo donde encontraste el error.
- Describe los pasos para reproducirlo.

2. Proponer mejoras
Si deseas agregar una nueva funcionalidad o mejorar el proyecto:

- Describe la mejora que deseas implementar.
- Explica por qué sería útil para la tienda.
- Indica qué archivos podrían modificarse.
- Espera la revisión de la propuesta antes de realizar cambios importantes.

3. Proceso de colaboración
Para colaborar en el proyecto se recomienda:

- Crear un fork del repositorio.
- Clonar el repositorio en la computadora.
- Crear una rama con un nombre descriptivo.
- Realizar los cambios necesarios.
- Comprobar que todo funcione correctamente.
- Registrar los cambios mediante un commit.
- Enviar los cambios con un Pull Request.

4. Checklist antes de enviar un Pull Request
Antes de enviar una contribución, verifica lo siguiente:

 [x]El código funciona correctamente.
 [x]Los cambios realizados están relacionados con la propuesta.
 [x]No se modificaron archivos innecesarios.
 [x]Se probaron las funcionalidades modificadas.
 [x]El commit tiene un mensaje descriptivo.
 [x]El Pull Request explica los cambios realizados.
 [x]Se menciona el número del Issue relacionado.

5. Recomendaciones
- Mantener un código ordenado y fácil de comprender.
- Utilizar nombres descriptivos para las variables y funciones.
- Revisar los cambios antes de publicarlos.
- Mantener una comunicación respetuosa con los colaboradores.


6. Nombres de ramas.

Se recomienda utilizar nombres descriptivos para las ramas, por ejemplo:

- fix-total-carrito
- mejora-diseno
- actualizar-documentacion

TODA CONTRIBUCION DEBE MANTENER EL ORDEN Y EL FUNCIONAMIENTO CORRECTO.

Gracias por contribuir al proyecto Tienda TECSUP.
